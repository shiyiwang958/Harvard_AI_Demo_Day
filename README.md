# One-Step Generation: Harvard AI Demo Day

A temporary one-page site for the Harvard AI Demo Day pitch. The project page is https://tullebulle.github.io/projects/sbm/.

It is a static site with no build step: `index.html` plus `assets/`.

- `assets/fig1_teaser_sbm.jpg` is the figure shown on the page.
- `assets/fig1_teaser_sbm.png` is the full-resolution figure, which opens on click.

The site is served by GitHub Pages from branch `main`, folder `/` (root).
